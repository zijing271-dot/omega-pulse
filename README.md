# ⚡ OMEGA Pulse

**AI-Powered API Monitoring SaaS** — self-healing, 429-aware uptime monitoring with zero false alerts.

Stop losing revenue to silent API downtime. OMEGA Pulse watches your endpoints 24/7, distinguishes real outages from rate-limits, and alerts you only when it matters.

## Features
- 🔁 Self-healing checks — retries and back-off before alerting
- 🚦 429/rate-limit aware — no noise from throttling
- 📈 Uptime & latency tracking
- 💳 Stripe billing built in

## Quick start
```bash
npm install
npm start        # runs api-monitor.js
```
Requires Node.js >= 18.
